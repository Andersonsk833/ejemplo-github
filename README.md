# Informe: Servicios Digitales y Almacenamiento en la Nube

## Descripción
Este repositorio contiene el informe técnico sobre **Servicios Digitales y Almacenamiento en la Nube**, desarrollado como ejemplo práctico de uso de GitHub como servicio SaaS.

## Objetivo del ejercicio
Demostrar de forma práctica los siguientes conceptos del informe:

- **SaaS** (Software as a Service) → GitHub es un servicio en la nube
- **Almacenamiento en la nube** → Los archivos se guardan en servidores remotos
- **Versionado** → Historial de cambios (commits)
- **Colaboración y acceso multiplataforma**
